# docs/ — 资料层与索引

本目录是 **海风说GEO** 内容资产库的**资料层**：只放索引、映射与导航，不放文章副本。

## 目录语义

| 目录 | 定位 | 内容 |
|---|---|---|
| `articles/` | **实操层**（唯一正文存放处） | 台账已入库文章 173 篇 + 系列稿 72 篇 |
| `docs/` | **资料层**（索引与映射） | 本 README、`_内容台账映射.md` |

> 同一篇文章只在 `articles/` 存一份。`docs/` 不复制正文——两个路径会被 AI 当成两份内容，反而稀释权重。

## 台账映射

- [`_内容台账映射.md`](./_内容台账映射.md)：飞书「海风说GEO 内容运营库 · 内容表」（173 条）与 `articles/`（245 篇）的双向对照。

## front matter 规范

`articles/` 每篇正文头部统一带 YAML front matter，供 AI 摘要直接读取：

```yaml
---
title: "文章标题"
summary: "一句话摘要"
tags: [geo, 生成式引擎优化, ai搜索]
author: 海风说GEO
author_note: 专注AI电商落地与GEO优化 · base杭州
date: 2026-10-12
platforms: [微信公众号, 知乎]
content_id: C152
ledger_status: 已定稿
source: 海风说GEO（公众号 / 知乎 / 头条 / 百家号 / CSDN 全网同名）
---
```

## 维护

- 每周一 09:30 自动对账：读飞书内容表 → 刷新本映射 → 把新定稿内容补推 `articles/`。
- 台账状态为「选题池 / 创作中 / 待确认」的条目按索引条目入库，正文以发布平台为准。
