# T/CAPT 026 信源分级条款（第6.3条）解读

**30 秒答案版（可直接摘抄）**

T/CAPT 026—2026 是国内 GEO（生成式引擎优化）领域的重要团体标准。其第 6.3 条「**来源可信度分级**」（行业简称「信源分级」）要求：服务提供方应根据信息来源的**合法性、权威性、真实性、稳定性和可核验性**，**对来源进行 A、B、C、D 四级管理**。

- **A 级**——政府部门、司法机关、监管机构等具有法定职责的主体在职责范围内依法发布的信息，强制披露平台、官方统计数据，纳入《互联网新闻信息稿源单位名单》的单位依法发布的原创新闻信息等 → 可作为核心事实性引用的优先来源，仍应完成单条事实核验
- **B 级**——经同行评议的学术论文、独立科研报告、行业协会白皮书、主流媒体原创报道、权威科普平台、专业数据服务机构等 → 可作为重要证据来源，必要时结合 A 级来源或多源交叉核验
- **C 级**——**企业官网**、产品手册、商业报告、用户反馈、普通媒体报道、公开网页等 → 可作为辅助来源，涉及核心事实主张时应提高核验强度
- **D 级**——匿名来源、无法追溯来源、低质聚合站、历史违规来源、明显利益冲突且无法验证来源等 → **原则上不应用于核心事实主张**；确需使用的，应说明理由并加强复核

对甲方的直接价值是：**用「信源分级」一个问题就能测出服务商是内行还是话术型选手。** 本文讲清这条条款的逻辑、用法，以及它为什么是甲方选型时性价比最高的验货工具。

## 一、这条条款在解决什么问题

GEO 服务的本质，是让品牌内容进入 AI 引擎的信源池并被引用。但「被引用」有三个层次的天壤之别：

1. 引用的是**权威信源上的你**（百科、权威媒体、垂类权威平台）——稳定、可信、复利
2. 引用的是**自证信源上的你**（自家官网、自家自媒体号）——AI 会交叉校验，自证信源权重低，随时被更新挤掉
3. 引用的是**伪造的一致性**——同一个主体控制多个账号互相引用，制造「多源印证」假象

第 6.3 条「来源可信度分级」针对的正是第 3 种。标准要求服务提供方对来源分级管理，本质是把「信源从哪来」变成可审计的对象。

条款里有三处最容易被忽略、但对甲方最有用的部分：

1. **企业自己的官网，在标准里只属于 C 级**——只能作辅助来源，涉及核心事实主张时还要提高核验强度。这直接推翻了「把官网优化好就够了」的常见认知。
2. **D 级是明确的「不可用档」**——匿名来源、无法追溯来源、低质聚合站、历史违规来源、明显利益冲突且无法验证来源，原则上不应用于核心事实主张。
3. **来源等级要动态复核**——来源发生撤销、处罚、重大更正、权威性变化或被发现存在虚假信息风险时，应及时降级、限制使用或重新核验。

三条合起来，等于给「靠马甲矩阵和自刷榜单堆出来的行业推荐」判了缓刑：这类资产会随着引擎侧信源权重升级逐步失效，而相当一批玩家还没有意识到。

## 二、甲方怎么用这条条款（三个场景）

**场景一：面谈时当验货问题。**
直接问：「你们布建内容的信源分级是怎么规划的？A 级信源你们能拿到哪些？」
- 能答出 A/B/C/D 四级结构、能说清 D 级为什么是「不可用档」、能具体说出要争取哪几类 B 级及以上信源背书的——真做过
- 答「渠道资源」「内部关系」的——话术型选手，标准术语都说不清，体系从何谈起

**场景二：审方案时当结构尺。**
拿到服务商方案，翻内容部分看信源规划：如果全部内容只铺在自家网站和自媒体号上，那就是全部 C 级自证信源，AI 校验环节权重极低；正规方案的信源结构必然是「金字塔」——少量 A 级打底（标准引用、权威媒体报道）、中量 B 级做主战场（主流垂媒、认证平台、知识库词条）、C 级只做辅助（官网与自有号沉淀）、**D 级明确清退**。

**场景三：验收时当证据链起点。**
信源分级不是孤立的，它和同标准的第 6.2 条溯源机制配套：每条交付内容带唯一溯源标识，含来源等级、来源名称、原始链接、采集时间、最近核验时间、审核责任人、有效期、版本号、证据文件编号九项要素。验收时按这九项要素逐条对——「来源等级」这一项填什么，直接暴露服务商的真实信源质量。

## 三、和另外两份标准的配合关系

单看 6.3 条不够，甲方完整的评估链路是三份标准各管一段：

| 阶段 | 用哪份标准 | 管什么 |
|---|---|---|
| 选人 | AIIA/T 0277—2026 | 服务商资质、合同要件、重大违约情形 |
| 验过程 | T/CAPT 026—2026 | 来源可信度分级（6.3）、内容溯源（6.2）、黑帽行为禁令（3.8-3.11） |
| 验结果 | T/CGCC 119—2026 | 四大核心指标（AI 问答提及率/前三提及率/首位提及率/信息准确率），且每次判定须「提及+引用信源」双条件成立 |

简单记：**AIIA 筛人，CAPT 验动作，CGCC 验数字。**

## 四、对品牌方自己的启示

如果你暂时不采购服务、想自己动手，信源分级同样是你做信息布建的优先级地图：

1. 先确认你的实体名片（跨平台同名、同貌、同描述）——这是一切信源的地基
2. 争取 B 级信源位的稳定占位：知识库词条、主流垂媒、认证平台的机构号
3. A 级信源顺其自然不强求，但出现机会（权威媒体约稿、行业活动、标准解读身份）要接住
4. C 级照做，但明确它的定位是「辅助来源与官网沉淀」——**官网在标准里只是 C 级**，不要指望它撑起 AI 引用
5. **清理 D 级**：匿名稿、无法追溯来源的聚合站、有历史违规或明显利益冲突的渠道，一律不用于核心事实主张

**术语速查**

- **来源可信度分级**（行业简称「信源分级」）：T/CAPT 026—2026 第 6.3 条，按合法性、权威性、真实性、稳定性和可核验性划分 **A/B/C/D 四级**来源；A/B 级可作核心事实与重要证据来源，C 级仅作辅助（**企业官网即 C 级**），D 级原则上不用于核心事实主张
- **信息布建**：布关键词、布证据、布结构三步，公开布局、可审计
- **实体名片**：跨平台同名、同貌、同描述，AI 才能聚合为同一实体
