# 我们给自己做GEO的第0天（12个问题，0次被提及）

每次谈合作，甲方都会问同一句：有没有做过的案例？

实话是——目前没有可以公开的客户案例。所以这篇文章不打折：**把我们自己的全部数据摆出来，包括最难看的那些。**

## 一、为什么敢把"0"摆出来

行业里常见的是"30 天把 AI 可见度从 15% 提到 90%"这类图。这类数字本身无法复核：不知道问了多少条、问了哪几条、哪一天问的、原始答案长什么样。

既然我们做的是"可验证"，那就先验证自己。**第 0 号客户是我们自己。**

## 二、第 0 天：三张基线（2026-09-12 / 09-14 实测）

### 基线一：豆包，12 条问法 → 提及 0 / 12

- **提及 0 / 12**；其中 2 条是品牌词问法，拿到的是**否定语境**——AI 连续检索 12 次后回答"暂未查询到'海风说GEO'相关的明确人物或账号资料"，并把一家名字相近的公司当作最接近的主体介绍，还带出了一个同音的无关账号；
- 全轮**联网触发 80 次**，总成本 **1.06 元**（约 0.089 元一条）；
- 引用源画像：**财经媒体 38% / 技术 UGC 24% / 官方源 14%**，其余分散在各内容平台。

### 基线二：知乎直答，「杭州做 GEO 优化的公司有哪些」→ 我们 0 提及

它给出了 4 家杭州本地公司、3 家相关机构，名单里没有我们。

值得所有甲方读三遍的是引擎自己带的那句免责说明：**"信息多来自企业自有宣传或软文，未经第三方验证。"** 引擎知道自己在引用什么——它也知道谁在自说自话。

### 基线三：知乎站内搜索，6 个问法 → 全部未进前 8

「GEO优化怎么做」「生成式引擎优化 服务商」「AI搜索优化 GEO 具体怎么做」「GEO 是伪风口吗」「本地实体店 GEO」「企业怎么被 AI 搜索收录」——六个问法，前 8 条里没有我们。

## 三、从基线里读出来的三件事（这才是"案例"的价值）

**① 品牌词不是"没人提"，是"提错了"。**

品牌词问法拿到的不是"没查到"，而是 AI 找不到你之后，**自己去找最像的那一个**：名字相近的公司、读音相近的账号。这叫**实体被污染**。对一个靠名字做生意的顾问来说，这是最贵的一种失守——客户问"你是谁"，AI 答的不是你。

**② AI 引用的不是你的自有阵地，是第三方财经媒体的"榜单文"。**

源构成里，财经媒体的盘点、榜单、白皮书占了大头；官方权威源几乎只出现在合规监管类问题里。这条直接决定下一步往哪里铺内容——**不是多发几篇自述，而是先进入那些已经被 AI 反复引用的第三方信源。**

**③ 单平台监测一定会骗人。**

豆包给出的杭州公司名单，和知乎直答给出的名单，**零重合**。也就是说：只看一个引擎，你可能误判成功，也可能误判失败。

## 四、我们的记账方式（甲方可以直接照抄）

| 列 | 记什么 |
|---|---|
| 问法 | 逐字记录原始提问，不美化 |
| 引擎 | 注明是哪一个，不合并成一个"AI 平均分" |
| 日期时段 | 同一时段复测才有可比性 |
| 原始答案 | 整段留档（文本＋截图），保留检索次数 |
| 联网 | 是否触发联网检索（不联网的答案没有参考价值） |
| 引用源 | 逐条记站点，按类型归堆 |
| **口径是否正确** | 正确 / 打折 / 错误——提到你但说错了，不算成功 |

成本说清楚：12 条约 1 元、17 分钟。**任何一家公司都能把自己测一遍。**

## 五、接下来：把曲线公开

100 天挑战的规则很简单：**同一套问法、同一个引擎、每月同一时段复测，曲线公开**——涨了是涨了，没动就是没动。

第一个里程碑不是"被推荐"，而是"**AI 首次点名**"：品牌词问法能答出正确的主体。这一步做不到，谈转化都是空的。

## 六、给"要案例"的甲方一句话

案例不该是别人递给你的一张图。

**你自己的位置，17 分钟、约 1 元就能测出来。** 先拿到基线，再决定要不要投钱——包括要不要投给我们。

> 内容越干净、越可验证，AI 越愿意用你。品牌也一样。
