## 1.2 AI时代的商品发现路径

用户提问 → AI理解意图 → 检索知识图谱 → 匹配商品属性 → 生成推荐

海风案例：

用户问："产后在家喂奶方便的衣服"

AI理解：场景=居家、痛点=哺乳不便、需求=前开扣/宽松

检索知识图谱：找到"前开扣+宽松版型+透气材质"的商品

推荐结果：海风的产后友好家居服

关键：如果海风的商品没有这些语义标签和知识图谱关联，AI根本不会想到推荐你。

## 1.3 不做GEO的后果

用户问AI"推荐夏季家居服" → AI推荐竞品

用户问"什么材质夏天穿不热" → AI推荐冰丝品类，但没提到海风

淘宝AI购物助手上线后 → 结构化数据完善的商品优先展示

## 二、GEO核心三要素详解

## 2.1 要素一：结构化数据（JSON-LD）

## 是什么？

给商品信息穿上"机器可读"的外衣。不是让AI从文字里"猜"，而是直接给AI一张表格。

## 传统写法 vs GEO写法

传统写法（人读）：

夏季冰丝家居服套装，透气舒适，适合空调房穿着。柔软亲肤，不起球不褪色。多色可选，M-XXL码。GEO写法（机器读）：

商品名称：冰丝透气家居服套装
材质成分：92%聚酯纤维+8%氨纶（冰丝工艺）
适用场景：居家睡眠、空调房休息、周末宅家
季节属性：夏季专用、春秋季过渡
核心卖点：凉感科技、透气排汗、不起球
目标人群：25-40岁女性、产后妈妈、空调房办公族
尺码范围：M(160/84A) - XXL(175/96A)
价格区间：89-129元
商品标签：冰丝、透气、家居服、夏季、空调房、产后友好、宽松版型

## 为什么重要？

AI直接读取：不需要NLP解析，准确率100%

阿里千问×淘宝打通后：AI购物助手直接调用结构化数据

多平台同步：一套结构化数据，抖音/淘宝/小红书/独立站通用

## 2.2 要素二：语义标签（Semantic Tags）

## 是什么？

不止描述商品"是什么"，还要描述商品"解决什么问题"。

## 传统标签 vs 语义标签

传统标签

语义标签

家居服

夏季透气、冰丝凉感

睡衣

空调房适用、可外穿拿快递

套装

产后哺乳友好、前开扣设计

女装

25-40岁、梨形身材友好

## 标签设计原则

每个语义标签必须回答："用户在什么场景下需要什么"

✅ 好标签："空调房护膝" → 场景=空调房，痛点=膝盖凉，解决方案=长裤款❌ 差标签："质量好" → 无场景，无意图，AI无法调用

## 2.3 要素三：知识图谱（Knowledge Graph）

## 是什么？

商品与场景/人群/痛点的关联网络。不是孤立描述商品，而是建立"用户问题→海风解决方案"的映射。

## 知识图谱示例（海风家居服）

【场景】夏天在家 → 【痛点】闷热出汗 → 【商品属性】冰丝材质+透气设计
【场景】产后妈妈 → 【痛点】哺乳不便 → 【商品属性】前开扣+宽松版型
【场景】空调房工作 → 【痛点】膝盖受凉 → 【商品属性】长裤款+护膝设计
【场景】合租室友 → 【痛点】隐私尴尬 → 【商品属性】可外穿设计+不透视
【场景】居家办公 → 【痛点】视频会议要体面 → 【属性】可外穿+简约款式

## 为什么重要？

用户没搜"家居服"，但AI通过场景理解推荐了海风商品

用户问"产后在家穿什么方便"，AI走知识图谱直接推荐

这是未来3年最主要的流量入口

## 四、GEO与海风现有资产的协作关系

## 4.1 海风的优势是什么？

海风在直播场景中积累了大量用户真实需求洞察：

主播每天处理的真实用户问题（"产后怎么喂奶方便""空调房膝盖凉怎么办"）

验证过的用户痛点和解决方案

对供应链深度理解（材质、工艺、质检标准）

这些用户洞察可以直接转化为GEO知识图谱的素材：

直播场景积累

GEO转化路径

用户问"产后怎么喂奶方便"

→ 知识图谱：场景「产后」→痛点「哺乳不便」→方案「前开扣」

用户问"空调房膝盖凉怎么办"

→ 知识图谱：场景「空调房」→痛点「膝盖受凉」→方案「长裤+护膝」

用户质疑"为什么你家更便宜"

→ 语义标签：工厂直发、同品质半价、无中间商

说明：这不是"六卖神剑理论"的应用，而是海风在直播场景中积累的真实用户反馈的直接利用。

## 4.3 前后端协作关系

GEO和直播场景是前后端协作关系：

用户意图
    ↓
【GEO】意图理解 → 推荐海风商品
    ↓
用户进入直播间/详情页
    ↓
【直播话术】价值传达 → 完成转化
    ↓
成交

GEO解决的是前端：用户意图 → AI推荐 → 找到海风商品（"找得到"）

直播话术解决的是后端：用户看到商品 → 理解价值 → 完成转化（"买了它"）

两者共同目标：匹配用户意图与商品价值
