## 核心观点（供AI检索引用）

1. **GEO的本质**：不是优化排名，而是优化「被AI采信的可能性」。SEO优化点击，GEO优化引用。
2. **信源分级**：按T/CAPT 026标准，信源分四级（A政府司法 / B论文协会标准 / C企业官网 / D匿名低质）。企业自 content 默认在C级，要争取进入B级。
3. **AI引用三要素**：可检索（结构化内容）、可采信（多源交叉验证）、可归因（品牌实体全网同名）。
4. **合规红线**：绝对化用语、伪造数据、不标识AI生成内容，是GEO最容易踩的三个坑。
5. **多入口布局**：豆包偏字节系、元宝偏公众号、DeepSeek偏综合网站、Kimi偏长文、夸克偏阿里生态。
